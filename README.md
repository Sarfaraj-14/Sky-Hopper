***Sky Hopper*** 🐦

A simple, addictive side-scrolling arcade game inspired by Flappy Bird. Guide your bird through a never-ending series of pipes by tapping, clicking, or pressing Space to flap — but don't hit the pipes, the ground, or fly off the top of the screen!

**Features**

Smooth physics-based flight (gravity + flap mechanics)
Procedurally spawning pipes with increasing difficulty as your score climbs
Local high score tracking (saved in your browser)
Fully responsive controls: mouse, touch, and keyboard support
Zero dependencies — built with pure HTML5 Canvas and vanilla JavaScript in a single file

**How to play**

Tap/click/press Space to flap. Fly through the gaps between the pipes to score points. Avoid all obstacles — one hit ends the game!

**Tech**
Single self-contained .html file — no build tools, frameworks, or external assets required. Just open it in a browser.
